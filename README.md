# Log Analyzer 

## Description
    This project analyzes a log file generated by devices and creates a report showing the number of occurrences of each log level (INFO, WARNING, ERROR, etc.). 

## Requirements
    - Python 3.x
    - No external libraries needed

## Features
    - Reads log files from a text file
    - Counts occurrences of log levels
    - Supports dynamic log levels (INFO, WARNING, ERROR, etc.)
    - Generates a report.txt file
    - Sorts results by frequency
    - Handles missing files gracefully

## Project Structure

    log_analyzer/
    │
    ├── log_analyzer.py
    ├── logs.txt
    ├── report.txt
    └── README.md

## How to Run
    - Place your log file in the same folder as log_analyzer.py.
    - Run the program:
    ```bash
       python log_analyzer.py
    ```
    - User will input the name of the text file.
    - The program will output a generated report through a text file.

## Expected Log Format
    YYYY-MM-DD HH:MM:SS LEVEL Message

    Example:
        2026-05-31 08:00:01 INFO Server started successfully

## Sample Input
    File: (name of text file)

    Inside the text file:
    2026-05-31 08:00:01 INFO Server started successfully

    2026-05-31 08:01:12 INFO User 'juan' logged in
    2026-05-31 08:02:34 WARNING High memory usage detected: 85%
    2026-05-31 08:03:45 INFO User 'maria' logged in
    2026-05-31 08:05:00 ERROR Failed to connect to external API
    2026-05-31 08:06:23 INFO User 'pedro' logged in

## Sample Output
    Generated a new file called report.txt

    Inside the report.txt
    Report Generated: (Date when the report has generated)

    INFO: 5
    ERROR: 2
    WARNING: 2

## Error Handling

    - Displays "File not found" if the specified file does not exist
    - Ignores blank lines in the log file
